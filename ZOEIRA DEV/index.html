    Aprendizado sobre JavaScript

    1. Javascript foi a automação que Deu funcionalidade nos botões
    2. function significa um bloco de código que so roda quando é chamado
    3. insert significa inserir ou colocar nome da função
    4. Ela so recebe uma informação chamada num
    5. Button significa um botão para que possa ser clicado como "button onclick=insert('7')"
    6. Onclick Significa que quando o botão é clicado, a função especificada é executada
    7. clean significa limpar o resultado total da calculadora
    8. num é uma variavel/parametro da função insert.
    9. var serve para criar uma varial, variavel é uma caixinha que guarda as informações
    10. document.getElementById() é uma função que permite selecionar um elemento do HTML pelo seu ID
    11. Numero é o nome da variavel que acabei criando para gerar os numeros da calculadora
    12. Document significa o documento HTML inteiro
    13. InnerHTML é uma propriedade que permite acessar ou modificar o conteúdo HTML de um elemento
    14. id é um nome especial para identificar um elemento no HTML
    15. back é o nome da função que apaga o último caractere do resultado
    16. resultado é uma variavel para guardar o que está no visor
    17. substring é um método que extrai uma parte de uma string, no caso ele extrai o resultado do visor menos o último caractere
    18. Length significa tamanho, ele conta quantos caracteres existem
    19. calcular é o nome da função que realiza o cálculo quando o botão "=" é clicado
    20. if significa "se"
    21. else significa "senão"
    22. eval é uma função do JavaScript que tenta calcular um texto como se fosse um codigo
    23. rowspan significa linha e colspan significa coluna, eles servem para juntar as células da tabela, no caso do botão "=" ele tem o rowspan="2" para juntar as células de baixo e do lado
